## 修复 useTranslate is not a function（关键 API 误用）
- 报错：`(0, _docusaurus_Translate...useTranslate) is not a function`，涉及 off-grid.js / TopBanner / MiddleStatsCard / MainContentTop / more.js 五个 i18n 文件。
- **根因（重要）**：Docusaurus **3.10 根本没有 `useTranslate` hook**！`@docusaurus/Translate` 只导出 `Translate`（默认组件）和 `translate`（imperative 函数）。`useTranslate` 是 **Docusaurus 4.x** 才有的 API。阶段2-前半的 i18n 改造错误地用了 `import { useTranslate } from '@docusaurus/Translate'`，dev 运行时访问该页才触发，故之前"构建通过"只是没跑到这些路由。
- **修复**：五个文件统一改为 `import { translate } from '@docusaurus/Translate'`，模块顶层定义包装 `const t = (...args) => { const [opts, values] = args; if (typeof opts === 'string') return translate({ id: opts }, values); const vals = values ?? opts?.values ?? (opts?.count !== undefined ? { count: opts.count } : undefined); return translate(opts, vals); }`，并删除组件内 `const t = useTranslate();`。所有 `t({ id, message })` / `t({ id, message, count })` 调用形式保持不变。
- lint 全部 0 错误。`translate` 读 `@generated/codeTranslations`，dev 下回退 message、en 下取 code.json，设计一致。

## 铁律（追加到 MEMORY.md）
- **Docusaurus 3.x i18n 只能用 `translate` 函数或 `<Translate>` 组件，绝不能用 `useTranslate` hook**（那是 4.x API）。
