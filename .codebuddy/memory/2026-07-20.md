2. **/app 404 Vercel 部署指导（用户问"先回答这个怎么做"）**
  - 架构：主站 /app/* → rewrite 到 Edge 函数 `api/app/[...path].js` → fetch `NEXT_APP_ORIGIN + /app + 路径`。该函数 `NEXT_APP_ORIGIN` 兜底 `https://next-app-mocha-three.vercel.app` 不存在 → 404。结论：不是"nextjs 没绑主域名"，是 next-app 没独立部署 / 主项目没设环境变量。
  - 步骤：A) Vercel 用同一仓库新建项目，Root Directory=`apps/next-app`、Framework=Next.js、Deploy 拿域名（可绑自定义域）。next-app 已设 `basePath:'/app'`，勿去掉。B) 主项目 Settings→Environment Variables 加 `NEXT_APP_ORIGIN=https://<next-app域名>`，勾 Production，保存后 Redeploy 主项目。C) 验证 /app 不再 404；仍 404 则查 Edge 函数日志的 target。
  - 可优化：把兜底域名改成"缺失即 500"，避免静默 404（用户未要求，待确认）。
