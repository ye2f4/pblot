## Vercel 构建失败（Export encountered errors 全部路径）根因与修复
- 现象：推送后 `pnpm run build` 在 `next export` 阶段对**所有页面路径**（含 `/`、`/_not-found`、`/chat`、`/forum`…）报 "Export encountered errors"。
- 根因：`apps/next-app/lib/docusaurusLinks.ts` 在早前那轮被**静默写成 0 字节**（写入无报错但内容丢失，符合"写入 No result found"的坑——这次甚至是单独写入也失败）。`AppNav`/`AppFooter` 仍 `import { transformNavItems }` 自该模块，模块为空 → `transformNavItems is not a function` → 每个页面 SSG 渲染都抛异常 → 全部路径 export 失败。
- 修复：重建 `docusaurusLinks.ts`（1488 字节），`transformToAppLink` 把 Docusaurus 配置 `to` 解析到 next-app 命名空间：`/app/*` 剥前缀留 `to`（next/link 的 basePath 自动补回 /app、active 高亮才能匹配 pathname）、主站路由（`/blog/` 等）改 `siteUrl` 绝对外链避免 404、外链 `href` 不变；`transformNavItems`/`transformFooterColumns` 递归处理下拉与列。已 commit `c203ea89` 并推送触发重部署。
- **教训**：写完文件（尤其新文件/关键模块）务必 `node -e` 或 read 校验字节数非 0，避免静默空文件进入部署。
