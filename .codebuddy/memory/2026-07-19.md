13. **/app 代理【最终可用方案】落地（本回合重大进展）**
   - **架构决策**：Vercel Hobby 免费计划会静默丢弃 `vercel.json` 里「rewrite 到外部域名」的规则（线上 /app/* 落主站静态 404 的根因）。改为 **vercel.json 内部 rewrite 到主站自己的 `api/app/[...path].js` 反向代理函数**（所有计划都支持），由函数在 Vercel 边缘网络内 fetch next-app（Vercel→Vercel 可达）。

   - **踩坑与修复（按顺序，都是真坑）**：
     1. **Docusaurus 构建在 Vercel 上传式部署（`vercel --prod --force`）失败**：上传构建环境**无 .git**，而 `docusaurus.config.js` 的 `showLastUpdateAuthor:true` 与 `sitemap:{lastmod:'date'}` 会在构建时调用 `git` 读 lastmod/lastUpdate → 报 `This Docusaurus site is outside any Git worktree` 整站构建失败。修复：关闭 `showLastUpdateAuthor`、sitemap `lastmod:null`（Docusaurus 3.10.1 的 lastmod 只接受 null/'date'/'datetime'，不支持函数）。→ 构建不再依赖 git，上传式部署也能成功。
     2. **函数必须用必需 catch-all `[...path]`**（非可选 `[[...path]]`）：可选型不匹配带尾斜杠的 `/api/app/forum/`，会落静态 404。
     3. **Vercel rewrite 到函数时，函数 `request.url` 看到的是【原始路径】**（如 `/app/forum`），不是重写后的 `/api/app/forum`。→ 函数里要剥离 `/app` 前缀（兼容直连再剥 `/api/app`），不能只剥 `/api/app`，否则拼出双 `/app`（`/app/app/forum`）导致 next-app 404。

     5. **必需 catch-all 不匹配空路径**：`/app`（根）→ `/api/app`（空）→ 404。修复：根路径用 **redirect** `/app`→`/app/forum/`（复用已验证路由），不放 rewrite。
