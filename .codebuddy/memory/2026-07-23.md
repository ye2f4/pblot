## 路由 API 崩溃修复（useNavigate → useHistory）
- 报错 `(0 , _docusaurus_router__rspack_import_1.useNavigate) is not a function`。根因：本仓库 `@docusaurus/router` 实为 **react-router v5** API，只导出 `useHistory`/`useLocation`/`Link`/`Redirect`/`Switch`，**不导出 v6 的 `useNavigate`**。迁移 next-app→Docusaurus 时误用了 v6 的 `useNavigate`/`navigate()`。

## 修复 “Loading chunk src_components_CommentSection_index_js failed (timeout)”
- 现象：dev 下首页 `CommentSection` 等 lazy 组件报 chunk 加载超时。根因 = Docusaurus `future.faster`（rspack）的 **dev server 不支持客户端 `React.lazy` 动态导入**（已知 faster 限制；node_modules 里没有 lazyCompilation，排除懒编译，是 rspack dev 根本不 serve 客户端 import() chunk）。生产构建不受影响（rspack prod 正常支持动态导入）。
- **修复**：`docusaurus.config.js` 的 `future.faster` 改为 `process.env.NODE_ENV === 'production'`——即**仅生产构建用 rspack 加速，dev 回退 webpack**（webpack dev 对 React.lazy 正常）。`src/pages/index.js` 三处 `lazy(() => import('../components/WeatherWidget|CommentSection|AdSection'))` 保持不动；`CarouselSection` 的 `react-slick` lazy 同理在 dev(webpack)/prod(rspack) 都正常。
- **关键约束（勿改）**：这三个首页组件 + CarouselSection 必须保持 `React.lazy`（不能静态 import），因为它们在 render 阶段访问 `window`/`localStorage`（CommentSection `window.location.pathname` in useMemo；WeatherWidget render 时读 localStorage；AdSection 已 `typeof window` 守卫）。`lazy()` 让组件在服务端 suspend、只跑客户端，从而避免 SSR `window is not defined` 崩溃。改静态 import 会破坏 SSR。
- 注意：`future.faster` 改了打包器，需**重启** `pnpm start`(docusaurus start) 才生效（dev 才切到 webpack）。
