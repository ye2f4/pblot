# 2026-07-26

## navbar/footer "根本不显示" 修复（删除 @mono/ui，设计内联）
- 用户纠正：问题不是"回退 Docusaurus 默认样式"，而是 navbar/footer **根本不显示**。
- 真因：`SiteHeader`/`SiteFooter` 设计放在外部 workspace 包 `@mono/ui`(`packages/ui/src`)，Docusaurus 默认不转译 `src/` 之外的 TS，导致 `import { SiteHeader } from '@mono/ui'` 解析到未转译源码 → 整组件渲染失败。
- 改动：
  1. 将 `SiteHeader` 设计内联进 `src/theme/Navbar/index.tsx`、`SiteFooter` 设计内联进 `src/theme/Footer/index.tsx`（均在 `src/` 内，必被转译）。
  2. `ui.css` 从 `packages/ui/src/ui.css` 移到 `src/css/mono-navbar-footer.css`，由两个 swizzle `import` 引入。
  3. 删除 `packages/ui` 目录；移除 `docusaurus.config.js` 的 `@mono/ui` alias + babel 转译规则（保留 `@` alias）；移除 `package.json` 的 `@mono/ui` workspace 依赖。
  4. 修正 `brand` 用 `title`（原误用 `label`，品牌文字不显示）；`DLink` 把 `href`→`<a>`、`to`→Docusaurus `<Link>`。
- 两个 swizzle 经 lint 0 错误。配置仍走 `src/data/siteData.json` 的 `navbarConfig`/`footerConfig`。
- 待办（未做）：`src/theme/Navbar/MobileSidebar/{Toggle,PrimaryMenu,Layout}` 是孤儿死代码，可清理。
