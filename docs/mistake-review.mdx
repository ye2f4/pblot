# 错题复盘方法——把失误变成经验

错题本不是“收集错误的地方”，而是**把失误转化为能力**的工厂。很多人的错题本看完就忘，问题出在“只抄不析”。

## 一、错题四问法

每道错题都要能回答：

1. **错在哪一步**？（计算 / 概念 / 审题 / 粗心）
2. **正确思路是什么**？
3. **我当时为什么那样想**？
4. **同类题怎么不再错**？

## 二、归类而非罗列

把错题按“错误类型”归类，比按科目归类更有用：

- 概念型：回到课本重新定义。
- 方法型：补一类题的通法。
- 习惯型：审题圈关键词、草稿分区。

## 三、间隔重做

- 当天：不看答案重做一遍。
- 三天后：再做一次。
- 一周后：纳入小测。

能连续三次独立做对，才算真正掌握。

## 四、让错题“开口说话”

给每道错题写一句**人话总结**，例如：“遇到‘至少’要先想补集”。这句话比抄十遍原题都管用。

> 同样的错误不犯第二次，就是最快的进步。
