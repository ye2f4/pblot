# 轻松备考心态——保持节奏，减少焦虑

备考拼的不仅是脑力，更是**心理韧性**。焦虑不会消失，但可以被管理。

## 一、区分“有用焦虑”和“内耗”

- 有用焦虑：提醒你“该复习了”→ 转化为行动。
- 内耗：反复想“考砸了怎么办”→ 立刻打断，回到手头任务。

## 二、把担心写下来

拿一张纸，把脑中的担忧全部写下，然后逐条写上“我能做的应对”。写出来的担心，杀伤力会减半。

## 三、保持身体节奏

- 每天运动 20 分钟，分泌内啡肽天然抗焦虑。
- 睡眠优先，熬夜只会放大情绪。
- 少刷“别人进度”的对比内容。

## 四、设定“最低可接受结果”

给自己一个底线预期，反而能轻装上阵。目标不是“必须完美”，而是“尽力就好”。

> 备考是一场和自己的合作，不是和别人的战争。保持节奏，你比想象中更稳。
