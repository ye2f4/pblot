# 刷题效率提升——精选练习，查漏补缺

很多人刷题陷入“题海战术”：做得多、错得也多，却总觉得没长进。真正高效的刷题，不是比数量，而是比**单位时间的收获**。

## 一、先诊断，再开刷

刷题前先回答三个问题：

1. 这个知识点我哪里不会？
2. 这类题的通用解法是什么？
3. 我之前在哪一步卡住过？

带着问题刷，才能把每一道题变成“补漏洞”的机会。

## 二、精选练习的 3 个标准

- **代表性**：覆盖一类题的核心思路，而不是偏题怪题。
- **梯度**：从基础到变式，循序渐进。
- **可复盘**：做错的题能清楚说出“错在哪一步”。

> 小提示：一道经典题做三遍，胜过三道新题各做一遍。

## 三、查漏补缺的闭环

建立“错题 → 归因 → 重做 → 拓展”的闭环：

1. **错题**：抄录或截图，标注日期。
2. **归因**：是概念不清、计算失误，还是审题偏差？
3. **重做**：隔天不看答案独立做一遍。
4. **拓展**：找 1–2 道同类变式验证掌握程度。

## 四、避免无效刷题

- 不要边看答案边做（那是“抄”不是“练”）。
- 不要只刷会的题（舒适区没有成长）。
- 不要刷完不总结（经验无法沉淀）。

刷题的本质是**用最少的时间，暴露最多的盲区**。把“练”变成“诊断 + 修复”，你的效率会肉眼可见地提升。
