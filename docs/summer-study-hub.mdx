# 暑假学习充电站——规划学习，也发展热爱

暑假是一年里最完整、最自由的整块时间。很多人要么彻底躺平，开学后悔；要么排满补习班，开学倦怠。真正高效的暑假，是**把“充电”和“热爱”都安排进去**——既要补弱科、前置新课，也要留出发展兴趣的空间。

## 一、先给暑假画一张地图

把暑假分成三段更容易坚持：

1. **启动期（前 2 周）**：调整作息、回顾上学期薄弱点、定目标。
2. **深耕期（中间 4–6 周）**：每天固定学习块 + 一个兴趣项目。
3. **收尾期（最后 2 周）**：复习巩固、预习新课、调整回学校节奏。

## 二、学习块怎么排

推荐 **上午主攻弱科，下午处理输入型任务，晚上留给热爱**：

- 上午 9:00–11:30：数学 / 英语等需要专注的科目
- 下午 14:30–16:30：阅读、看网课、整理笔记
- 晚上 19:30–21:00：编程、绘画、运动、音乐等兴趣

## 三、别丢掉“热爱”

研究一致表明，持续的内在动机比外部压力更持久。暑假正适合发展一项能让你“忘记时间”的爱好——它会在开学后成为你的情绪缓冲带。

> 小提示：用一张 A4 纸写下“这个暑假我最想做成的一件事”，贴在学习桌前。

## 四、避免三个坑

- **坑 1：计划过满**——留出 20% 弹性时间。
- **坑 2：只学不练**——每学完一个知识点立刻做 3 道题验证。
- **坑 3：忽视睡眠**——作息紊乱会拖累整个假期效率。

暑假不是用来“熬”的，而是用来“养”的。规划好，玩好，学好，开学你会感谢现在的自己。
