# 高考冲刺季——稳住节奏，不负努力

冲刺阶段比的不是谁更拼命，而是谁更**稳**。越临近考试，节奏感越重要。

## 一、保持正常节奏

- 不突然熬夜，不突然加量。
- 维持已有的作息和饮食。
- 把“平时当考试，考试当平时”。

## 二、抓大放小

最后阶段，果断放弃“性价比极低”的偏难点，把时间留给：

- 高频考点
- 自己的易错点
- 能稳定拿分的中档题

## 三、模拟考场状态

- 按高考时间段做套卷（上午语文/综合，下午数学/英语）。
- 训练“在规定时间内拿到最多分”的策略。
- 演练涂卡、时间分配等细节。

## 四、给努力一个交代

你已经走了很远的路。冲刺不是焦虑地赶路，而是**稳稳地走完最后一段**。

> 不负努力，不是考出多高的分，而是发挥出你应有的水平。
