# 高考备考指南——高效规划，稳步提升

高考不是冲刺百米，而是马拉松。胜负往往在**规划能力**上就已分出高下。一份能落地的备考规划，比十套押题卷更有价值。

## 一、三轮复习法

- **一轮（现在—次年 2 月）**：地毯式过课本，不留死角，重基础。
- **二轮（3—4 月）**：专题突破，建立知识网络，重综合。
- **三轮（5 月—考前）**：套卷限时训练，查漏 + 调状态。

## 二、把目标拆成可执行的动作

“我要考 600 分”是愿望，“本周弄懂导数 3 类题型”才是计划。用 **SMART** 原则把大目标拆成周任务和日任务。

## 三、学科平衡策略

- 优势学科：保住基本盘，每天少量维持手感。
- 弱势学科：集中火力，优先补“性价比最高”的模块。
- 临界学科：多投入 20% 时间，往往能跨过一个分数段。

## 四、每周复盘清单

- [ ] 本周计划完成度如何？
- [ ] 哪些知识点仍模糊？
- [ ] 下周的优先级是什么？

> 规划的意义不在于“列得多漂亮”，而在于**每周都能根据实际情况微调**。

稳步提升的关键，是把大目标切成小台阶，一步一步踩实。
