# Supabase 后端即服务实战

Supabase 是开源的 Firebase 替代方案，核心是一套带 Row Level Security 的 PostgreSQL，外加 Auth、Storage 与 Edge Functions。

{/* truncate */}

## 一、核心能力

| 模块 | 说明 |
| --- | --- |
| Postgres | 可靠的关系型数据库 |
| Auth | 邮箱 / OAuth 登录 |
| Storage | 文件对象存储 |
| Edge Functions | Deno 边缘运行的无服务器函数 |
| RLS | 行级安全策略 |

## 二、前端读取数据

```js
import { createClient } from '@supabase/supabase-js';

const supabase = createClient(URL, ANON_KEY);
const { data, error } = await supabase
  .from('posts')
  .select('*')
  .order('created_at', { ascending: false });
```

## 三、用 RLS 保护数据

```sql
create policy "公开可读" on posts
  for select using (true);

create policy "仅作者可写" on posts
  for insert with check (auth.uid() = author_id);
```
