# 开源硬件项目分享

开源硬件（Open Source Hardware）把电路设计、固件与结构文件公开共享，让知识像软件一样自由流动。本站长期记录各类 DIY 项目。

{/* truncate */}

## 一、一个项目的生命周期

1. **需求定义**：明确要解决的实际问题。
2. **原理图设计**：使用 KiCad 绘制电路，选型芯片与外围。
3. **PCB Layout**：注意信号完整性与散热。
4. **打样焊接**：嘉立创等厂商支持小批量低成本打样。
5. **固件开发**：Arduino / ESP-IDF / PlatformIO。
6. **文档与发布**：在 GitHub 开源，撰写 BOM 与教程。

## 二、常用工具链

```bash
# PlatformIO 快速编译上传
pio run            # 编译
pio run -t upload  # 烧录
pio device monitor # 串口监视
```

## 三、为什么开源

- 社区可以共同改进设计。
- 新手能站在巨人肩膀上学习。
- 透明可审计，更适合安全与隐私敏感场景。
